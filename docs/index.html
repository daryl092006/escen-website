Introduction

Vue d'ensemble

Le site ESCEN est une application Vue 3 / Nuxt 4 en mode statique (CSR). Il couvre deux grandes zones fonctionnelles : le site public (catalogue des formations, blog, galerie, inscriptions) et le portail candidat sécurisé (dossier, documents, notifications).

Configuration

Plugins

axios.ts

Configure l'instance Axios globale avec la base URL (dev/prod), l'injection automatique du Bearer token depuis localStorage.candidat_token, et la gestion des erreurs 401 (déconnexion + redirect vers /candidat/login).

// Comportement du plugin axios
baseURL: API_BASE_URL  // depuis config.ts

// Intercepteur request
config.headers.Authorization = `Bearer ${localStorage.candidat_token}`

// Intercepteur response — erreur 401
localStorage.removeItem('candidat_token')
localStorage.removeItem('candidat_info')
router.push('/candidat/login')

pixels.client.ts

Initialise les trois systèmes de tracking uniquement après le consentement cookies. Écoute l'événement cookies-accepted sur window et suit les changements de route pour le tracking SPA.

PixelDéclencheurCondition
Meta Pixelfbq('init', pixelId)consentement localStorage OU événement cookies-accepted
Google Analyticsgtag('config', gaId)idem
LinkedIn Insight_linkedin_partner_ididem

intl-tel-input.client.js

Expose $intlTelInput aux composants. Permet la saisie de numéros de téléphone internationaux avec sélection du pays et validation du format.

Backend

API & Endpoints

Tous les appels API passent par le plugin Axios. L'URL de base est https://escen.neostart.tech/api en production.

Endpoints publics PUBLIC

  • GET
    /public/blogs
    Liste tous les articles du blog
  • GET
    /public/blogs/{id}
    Détail d'un article de blog
  • POST
    /public/blogs/{id}/comments
    Ajouter un commentaire sur un article
  • POST
    /public/newsletter/subscribe
    Inscription à la newsletter (body: { email })
  • GET
    /public/galeries
    Liste des albums photo
  • GET
    /public/galeries/{id}
    Album photo avec ses images
  • GET
    /public/configurations
    Paramètres de configuration de l'application
  • GET
    /public/niveau/liste
    Liste des niveaux d'études (Licence, Master, etc.)
  • GET
    /public/filieres/liste?niveau_id={id}
    Filières par niveau d'études
  • POST
    /public/candidature/soumettre
    Soumission du dossier de candidature — multipart/form-data
  • POST
    /public/brochures/request
    Demande de téléchargement de brochure (nom, email, téléphone)

Endpoints protégés AUTH

  • GET
    /mon-dossier/notifications
    Notifications du candidat connecté
  • POST
    /me-deconnecter
    Déconnexion — invalide le token côté serveur
Authentification : Tous les endpoints /mon-dossier/* requièrent le header Authorization: Bearer {candidat_token}. Le plugin Axios l'injecte automatiquement.
Sécurité

Authentification

L'authentification est basée sur un token Bearer stocké côté client. Il n'y a pas de cookie de session — le token est géré exclusivement via localStorage.

Flux de connexion

ÉtapeActionStockage
1. LoginPOST credentials → /candidat/login—
2. Token reçuLe backend retourne un tokenlocalStorage.candidat_token
3. Profil reçuInformations du candidat stockéeslocalStorage.candidat_info (JSON)
4. Requêtes suivantesAxios injecte automatiquement le Bearer token—
5. Erreur 401Token expiré ou invalide détecté par l'intercepteurNettoyage localStorage + redirect login
6. DéconnexionPOST /me-deconnecter puis nettoyage localSuppression des deux clés localStorage
Tracking

Analytics & Tracking

Les trois pixels sont initialisés par le plugin pixels.client.ts uniquement après accord explicite du visiteur via le bandeau RGPD.

Conformité RGPD : Le plugin vérifie localStorage.escen_cookie_consent au chargement et écoute l'événement window.cookies-accepted. Aucun pixel n'est déclenché avant le consentement.
ServiceIdentifiantÉvénements trackés

Variables d'environnement

Les identifiants de tracking sont exposés via runtimeConfig.public dans nuxt.config.ts et chargés depuis .env.

# .env
NUXT_PUBLIC_META_PIXEL_ID=24431732409802544
NUXT_PUBLIC_GA_ID=G-X87RFP5GDP
NUXT_PUBLIC_LINKEDIN_PIXEL_ID=8182794
Note : API_BASE_URL et STORAGE_URL sont définis directement dans config.ts en fonction de NODE_ENV — pas de variable d'environnement dédiée requise pour ces URLs.
